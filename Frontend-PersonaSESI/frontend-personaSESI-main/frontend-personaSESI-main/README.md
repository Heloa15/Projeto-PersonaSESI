# Frontend do Persona SESI
- > O frontend é a parte da aplicação responsável pela interface com o usuário, permitindo a visualização e interação com o sistema por meio do navegador.

## Como Executar o Frontend

1. Clone o repositório
```git hub
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Acesse a pasta do frontend
```git hub
cd nome-do-projeto/frontend
```

3. Instale as dependências
```git hub
npm install
```

4. Configure o ambiente
```git hub
Crie um arquivo `.env` na raiz do frontend com suas variáveis de ambiente.
```

5. Execute o servidor de desenvolvimento
```git hub
npm run dev
```

6. Acesse a aplicação no navegador
```git hub
http://localhost:5173
```
